# 个人网站首屏改写提示词

为张建华 Erick 的个人作品集设计一个电影感、沉浸式首屏。身份为技术出身的 Forward Deployed Engineer，专注 AI 应用、智能体和工作流自动化。主标题使用“让想法，走向现实。”，说明从需求梳理、开发到上线交付的工作方式。主要入口为“查看作品”和“聊聊合作”，导航保留作品、合作、参考库、关于与联系。

视觉延续敦煌矿物色：米白、孔雀绿、朱砂、鎏金与深墨。使用本地原创背景：右侧有流动飘带、空间建筑与光线，左侧保持安静留白，确保中文内容可读。叠加轻微空间运动、细致金线与半透明玻璃质感控件；桌面与手机均须适配，尊重动态开关、系统减少动态设置，并在离屏或页面不可见时停止不必要的动画。图片加载失败或 JavaScript 不可用时应有可读回退。

只展示已确认信息：7 年互联网与 AI 行业经验、美国贝翰文大学 MBA、常驻上海及线上/预约线下。不要添加未经证实的客户数、评分、案例效果、订阅表单或访客数据。保留现有作品、项目实屏、参考资料来源及微信、电话、邮箱入口。素材应本地加载或有明确授权，避免把原 Lumora 提示中的第三方视频、火车图或虚构统计当作个人事实。

项目采用现有静态 HTML/CSS/JavaScript 与本地 Three.js/GSAP 实现，保持 GitHub Pages 可部署，不为视觉改版重建技术栈。以响应式布局、清晰对比度、键盘操作及加载性能为验收条件。
