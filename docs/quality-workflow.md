# 网站变更的轻量验收流程

本项目参考 [Spec Kit 的问题验证流程](https://github.github.io/spec-kit/guides/bugfix.html) 与 [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)，保留现有静态构建和项目规则。这里是本项目整理的工作方法，不是完整框架或技能安装。

## 先确定可重演的问题

写清访客当前遇到的现象、预期结果、受影响入口和本轮范围。区分真实项目资料、界面观察与推断；未经核验的能力不写成已实现的事实。

## 按职责拆分

- 设计研究：用实际界面定位问题，核实候选方案、许可和采用范围。
- 实现：只修改约定文件与功能，保留原生链接和失败退路。
- 独立检查：不以实现者的结论为证据，回放原场景并检查边界。

角色可以由同一轮的独立 Agent 协作承担；不因采用这份方法重建 AGENTS.md、修改授权范围或接入公开后台。

## v37 实屏画廊的验收契约

| 场景 | 必须可观察的结果 |
| --- | --- |
| 连续打开与切换三张实屏 | 每张图片、标题、alt、日期、原图和访问链接均对应自身作品；Playground 显示登录提示 |
| 原尺寸模式 | 世界杯1400×951、API1270×714、Playground725×604；不强行放大为统一1400px |
| 键盘操作 | 非原尺寸模式左右键切图；原尺寸方向键可滚动；Tab/Shift+Tab首尾循环；Esc关闭返焦 |
| 图片载入失败 | 状态明确、原尺寸按钮禁用、原图及项目入口保留；切到可用图片后恢复 |
| 快速操作与关闭 | 最后一次选择决定当前内容；旧图片回调不串入新图，关闭后不恢复旧状态 |
| 小屏与短屏 | 不横向溢出，关闭控件可见，原尺寸可滚动，缩略目录可操作 |
| 动效 | 开关关闭后动画停止；CSS保留系统减少动态效果规则。未模拟系统偏好时写明限制 |
| 脚本或dialog不可用 | 原链接可直接打开图片，Ctrl/Meta等修饰键不被普通点击逻辑截断 |

## 记录证据再发布

运行适用的构建、搜索、静态资源、语法与退役样式检查。浏览器回放记录当前视口与真实状态，截图取自最终界面；axe结果只作为自动检查证据。

出现失败先保留复现，再修复并重演同一场景。结论使用通过、部分验证、失败或未知，不把源码检查写成浏览器实测。推送后核对精确提交的Actions与公开资源，最后维护现有HANDOFF入口。
