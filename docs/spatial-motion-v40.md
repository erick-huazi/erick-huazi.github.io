# v40 星盘与轨道

首页场景以原创矿物核心、金色轨道、星盘刻度和星尘形成多层空间构图，保留朱砂、孔雀绿和金色飘带。镜头推进和轨道运动与原生滚动进度关联；文案、三个阶段和“直接看作品”仍由 HTML 提供。画布仅承担装饰，不承载业务入口。

作品区实屏使用边框、透视和悬停时的三维倾斜反馈；产品链接、站内大图画廊和图片说明仍是普通网页内容。动效受站内开关、指针和系统减少动态效果偏好约束，手机可直接浏览静态作品。

## 维护位置

| 文件 | 职责 |
| --- | --- |
| `src/spatial-intro.mjs` | 原创几何、相机和 GSAP 时间线；场景销毁时释放几何、材质和渲染器 |
| `dist/motion.js` | 初始化条件、动效开关、深链接、异步有效性检查和失败回退 |
| `dist/index.html` | 静态文案、阶段提示和原生作品跳转 |
| `dist/mineral-editorial.css` | 场景排版、作品实屏透视反馈与静态样式 |
| `scripts/build-assets.mjs` | 生成场景副本、样式及自托管依赖；记录资源哈希 |

修改源文件后运行 `npm run build`，不要直接编辑生成的 `dist/assets/spatial-intro.mjs` 或 `dist/site.css`。变更后需同步更新场景导入和页面脚本缓存参数，以免访客继续使用旧版本。

## 加载与退路

首页场景沿用既有按需加载条件：满足桌面窗口尺寸和精细指针、进入安全的开场区域、页面可见、动效开启，且无减少动态效果、省流设置或打开的对话框时才初始化。首次访问其他深链接不会为了开场改变目标位置。每次异步加载后都会重新检查资格，离开时迟到的场景不能安装。

滚动、指针交互以及可见时循环的缓慢自转与呼吸动画驱动绘制，场景不接管全站滚动。关闭动效、弹窗打开、离屏或页面隐藏时停止场景；WebGL 上下文丢失或加载失败时移除增强画布并恢复静态插画。窄屏、减少动态效果及脚本不可用时保留内容和原生链接。实际设备表现应以各版本测试为准。

## 验证边界

本地桌面浏览器已确认真实 WebGL ready、单 canvas 及三个滚动阶段。暂停动效时观察帧数 3916→3916，打开弹窗时 3959→3959；离屏停止，恢复后仍为一个 canvas。真实 WebGL 上下文丢失测试从一个 canvas 退回零个并显示静态画面。本地部分重入测试中，场景底边位于 60px 时帧数维持 17，移动至 160px 后帧数增至 46，说明该测试中可见时恢复绘制。

390px 视口检查无横向溢出且未初始化 3D。首次进入 HYALORIA 深链接时场景初始化次数为 0，目标顶部约 106px；实屏画廊三张图片正常。桌面与手机各完成一次 axe 检查，均为 0 条自动违规、2 项需人工判断。

上述结果来自本地浏览器与测试 fixture，帧数仅说明该观察区间内是否继续绘制，不是帧率或长期性能指标。尚未完成跨设备、真实慢网络、操作系统减少动态效果切换或完整读屏验证；自动检查不能替代人工辅助技术测试。发布状态以对应提交的 GitHub Actions 和正式站检查为准。
