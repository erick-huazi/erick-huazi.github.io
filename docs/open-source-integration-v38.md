## 已融合的界面与行为

首屏保留原矿物色与原创飘带，将四个应用入口改为两列目录，并压紧图文比例。常见桌面首屏可以同时看到主按钮与四个应用入口。四张作品画面中的重复英文类别和大编号已移除；类别、职责和真实截图日期仍在画面外保留。Playground摘要减少了与详情的重复描述，不改变功能边界、所属产品或个人分工。

作品区新增仅覆盖四个作品与应用的目录。1280px起为粘性侧栏，较窄屏幕为横向目录，短屏进一步压缩。当前项以aria-current和可见样式标记；数字表示当前条目位置，细线表示浏览位置，不表示已读或完成度。

目录从既有稳定ID对应真实卡片。只有作品区接近视口才监听滚动，每帧合并位置读取；筛选、展开、尺寸变化和历史恢复都会重新测量。被动滚动只更新目录状态，不写URL、不移动焦点、不持续播报。手机当前项仅在目录条内部横移，避免再次滚动整页。

归档筛选隐藏新应用目录并收回侧栏；原三个过往入口继续保留。搜索恢复作品后，目录和当前项随之恢复。点击新目录不强行聚焦标题，其他原入口和搜索继续沿用既有焦点策略。所有目录链接保留原生href，主脚本缺失时目录使用静态布局。

手机回放发现全局scroll-padding实际为88px，原源样式中的104px已被历史层覆盖。修复采用实际计算值抵消滚动留白，避免目录遮住眉题。修复后对320/390/760/761/1100/1279/1280/1440及短屏逐一回放，锚点均留在目录下方。

详情展开与画廊关闭还暴露了间距边界：阅读线落在两卡片之间、且更接近下一张时，目录曾停在上一张。现在仅在间距区按最近距离选择，卡片内部仍按阅读线；同一场景已重演确认。
